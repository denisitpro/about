Live

Fiat and crypto rates API in Go behind the apps. One collector polls several providers and is the only writer; stateless read replicas serve an in-memory snapshot with an ETag for app cold start. AI agents buy a pack of requests in USDC on Base over x402 and read the same rates over MCP. API курсов фиата и крипты на Go для приложений. Один коллектор опрашивает несколько провайдеров и единственный пишет; реплики без состояния отдают снимок из памяти с ETag для холодного старта приложения. AI-агенты покупают пакет запросов в USDC на Base через x402 и читают те же курсы по MCP.

lux-l7

Pre-alphaПре-альфа

L7 egress proxy in Go: clients reach one stable endpoint and name the real upstream per request (header or path), or use a static route table. Optional CONNECT tunnel relays raw TLS without seeing it. Token auth, SSRF guard, allow/deny lists, Prometheus metrics. Stateless, one static binary. L7 egress-прокси на Go: клиент ходит в одну стабильную точку и в каждом запросе называет реальный апстрим (заголовком или в пути), либо работает по статической таблице маршрутов. Опциональный CONNECT-туннель пропускает TLS насквозь, не заглядывая внутрь. Токены, защита от SSRF, allow/deny-списки, метрики Prometheus. Без состояния, один статический бинарник.
